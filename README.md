# SiteQuant Pro

Professional BBS + BOQ SaaS foundation for web and Android.

## v0.2
- Premium responsive BBS workspace
- Visual bar-shape selection
- Versioned BBS calculation engine
- Cutting length, bar count, kg/m, total kg and tonnes
- Calculation trace and standards metadata
- CSV export
- BOQ, projects, exports and pricing product surfaces
- Test harness

## Engineering note
The current calculation rules are a framework/prototype and must be reviewed and validated against the selected standards and project requirements before construction-issue use.

## Run
`npm test`
`npm run check`
`npm start`
